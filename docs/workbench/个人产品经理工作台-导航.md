# 个人产品经理工作台（从 Notion 迁入）

**Notion 源：** https://app.notion.com/p/405a86f5091581db9c4df699aea7f6c5

## 定位

把项目交付、产品工作、知识积累和方法论沉淀放在同一套体系里。

- **项目** 提供上下文
- **产品工作** 管理交付物
- **知识体系** 沉淀可复用认知
- **方法论** 沉淀做事方式

**使用原则：** 每条信息只维护一份；通过关联和不同视图复用。页面负责导航，结构化记录负责检索。

## 信息流

发现问题 / 用户反馈 / 竞品观察  
→ 调研条目（原文层 / 资料外链）  
→ 需求分析  
→ PRD 与规则（正式交付）  
→ 开发 / 测试 / Bug 验证  

调研同时可沉淀 → 知识点与技术原理 → 可复用方法论 → 再反馈到需求分析


## 知识范围（已确认，对齐 Notion）

Notion 里本来就是两层：

- **01 项目** 下挂各产品/模块页 → Star PM **项目知识**
- **03 知识体系 / 学习 / 我的笔记** → Star PM **个人知识**（不绑单一项目）
- **04 方法论 / 05 模板** → 默认归个人知识（跨项目）

所以不是「只能全局」或「只能当前项目」，而是和 Notion 一样：**个人区 + 各项目区**，个人工作台里都能看到。
