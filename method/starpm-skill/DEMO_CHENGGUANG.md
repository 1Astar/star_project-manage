# Demo · 晨光手记（对外沙盘）

用虚构产品讲清 **Idea → 需求池 → 任务**，避免泄露真实客户项目。

## 故事线（对外可讲 5 分钟）

1. **随口一句** → Agent 用 StarPM Method 建成 Idea，保留原话。  
2. **确认要做** → 转成 Requirement，标优先级，写 why。  
3. **领导改口** → Decision + 状态/优先级变更，时间线可回看。  
4. **隔很久再问** → 「现在做到哪 / 为什么停 / 下一步」从库里恢复，不靠聊天幻觉。

## 怎么看演示数据

在已部署的 StarPM 上：

1. 使用 **观看者** 账号（只读沙盘；账号见部署方说明 / 根 `README` 的 `VIEWER_*`）。  
2. 打开演示项目 **晨光手记**（`proj-demo-showcase`）。  
3. 浏览灵感 → 需求池 → 任务，对照上面四步讲。

本地开发者：

```bash
npm install
npm run dev
```

用 viewer 登录后只应看到演示沙盘（配置正确时）。

## 和 Method Skill 的关系

| 材料 | 作用 |
|------|------|
| 本 Demo | **人眼**看流程是否好讲 |
| `SKILL.md` | **Agent** 按同一套方法执行 |
| MCP | 把执行结果写进 Core |

对外演讲：**先讲 Method + 三场景，再打开晨光手记点两下。**
