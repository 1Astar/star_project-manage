# DOCX 文档生成规范

## 1. 技术要求

默认使用 Node.js + `docx` 库生成 Word 文档。

- 使用 `Packer.toBuffer` 输出。
- 文件编码统一为 UTF-8。
- 统一管理样式函数。
- 不使用未经配置的默认样式。
- 本仓库输出路径：用户指定目录，或项目内约定的交付目录；勿写死 `/mnt/user-data/outputs/`（跨机路径）。
- 输出前确认目录存在且可写。

如用户明确指定其他生成方式，按当前任务要求执行。

更细的商务排版 token 可叠加 skill `word-docx-professional`。

## 2. 文档设计原则

每份文档先确定统一的视觉主题。

- 使用一种主色体系。
- H1、H2、H3 使用主色深浅区分。
- 表头使用主色深色背景、白色加粗文字。
- 重要行使用主色浅色背景。
- 风险提示使用红色文字。
- 注释使用灰色文字。

整体风格：商务专业、现代简洁、层级清晰。

## 3. 字体

- 中文：Microsoft YaHei（微软雅黑）
- 英文及数字：Times New Roman
- 所有元素显式指定字体。
- 正文：五号 10.5pt，颜色 `#333333`。
- 注释：10pt，`#666666`。
- 警告：10pt，`#C00000`。

## 4. 页面

A4：宽 11906 / 高 16838 twips；页边距上下左右 1080 twips。

## 5–11. 段落／表格／列表／版本

段落间距、表格边框与表头样式、编号列表、封面页脚、样式函数封装、版本记录：按用户任务与 `word-docx-professional` 执行；版本号与 `version-management` 一致。

## 12. 生成前检查

字体统一、中文正常、标题层级清晰、表格不超出页面、无多余空白页、只改用户指定内容。生成后检查实际渲染效果。
