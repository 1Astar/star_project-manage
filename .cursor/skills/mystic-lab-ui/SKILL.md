# Mystic Lab UI：整页画布，不要条幅、不要框

用户原话（硬）：**「黑色的条幅也很丑很突兀」**；**「尽量不要用一个个的卡片的格式 一个个的框住」**。

## 原则

页面是**一块连续星夜/宣纸画布**。分区靠标题层级、间距、金色强调；不靠「再铺一层圆角矩形」。

## 禁止

| 禁止 | 长什么样 | 改成 |
|------|----------|------|
| **实心条幅** | 顶栏/吸顶 Tab 铺纯黑、炭灰、`--bg-deep` 实底，和页面底色切出一条横杠 | 文字/返回/角色名**浮在页面上**；必须吸顶时用**与 `--body-bg` 同色或全透明渐隐**，不要更深/更实的一条 |
| **区块卡片** | 每个标题+内容外包 `border + border-radius + --surface-1/--bg-panel` | 标题（金）+ 一句说明（灰）+ 内容；块与块之间用空白，最多一根发丝线 |
| **盒中盒** | 大卡里再套小圆角井（图标格、状态条、列表项人人一个框） | 图标+字直接铺在画布上；状态用字色/小点，不要再开一口井 |

CSS 味：给「一整段内容」加 `background` + `border-radius` ≥ 12px + `border`/`box-shadow`。解读页已有对照：`.bazi-reading-page` **无框线**；顶栏「自己」**不要胶囊框**。

## 允许（仅这些需要「面」）

- **真正的牌**：塔罗牌面、六爻爻画，那是对象不是版式
- **盖住页面的层**：弹层 / 抽屉 / 底栏 sheet
- **输入控件**：输入框、主按钮本身；不要再给整段流程套一张卡
- **首页体系入口砖**：去选「进哪个体系」；**内容页不要抄这套**

## 顶栏 / Tab

- 左返回、中角色名、右动作：透明底，字吃 `--ink` / `--ink-muted`
- Tab：字 + **金色下划线**；轨道透明，不要整条黑底
- 忌：`sticky { background: color-mix(in srgb, var(--bg-deep) 97%, transparent) }` 在略浅星空上变成一条黑杠（`.module-topbar` / `.bazi-codex-sticky-stack` / `.bazi-codex-tabs` 的现况）

## 找借口时停手

| 借口 | 事实 |
|------|------|
| 吸顶必须实底，否则字叠在内容上 | 贴页面纹理 / 轻 blur；实底一旦比页面更深就是条幅 |
| 卡片才有层次 | 层次用字号、金/灰、间距；框是把画布切碎 |
| 就这一张 CTA 卡 | 徽标+标题+按钮直接放画布上 |
| 仪表盘/shadcn 默认 Card | Lab 不是后台 |
| 毛玻璃显得高级 | 仍是框；内容页不用 |

做 Lab 界面时：**先问会不会多出一条横杠、会不会多一个框。会 → 删掉底和边，只留字与间距。**
