# 延期范围落盘（不做 / 后期）

用户说 **不做、后期再做、先做 A 再补、记到 PM** 时：禁止只写一句「后期补某某」。必须落到 **Skill 规范 + Star PM Idea**，让半年后仍能开做。

与 `star-pm-write-release` 联用：本 skill 管**延期条目怎么写**；写完后的字段/状态仍走 PM 写入标准。

## 硬规则

1. **本期定稿若列「不做」** → **清单上每一项**立刻建或更新为 **父需求下的子需求 / 父 Idea 下的子 Idea**，填满延期卡；**禁止**只留聊天，也禁止平级散落成顶层任务。  
2. **一起提出来的，不要厚此薄彼（硬）**：同一句裁切 / 同一张「不做|后期」表里的条目，落盘时必须 **同级、同模板、同优先级档、同等详细度**。禁止只给其中一条写长文释义、单独开 skill 专节、或单独抬成「主延期项」，其余只写半句。可分期实现，但**记账必须一视同仁**。  
3. **父子结构**：整包/延期包是父；拆出的条目全是**平等子节点**。灵感 `relatedIdeaId` / `link_item relationType=parent`；需求 `parentId`（父 `epic`、子 `feature`）。  
4. **禁止**整包 `done` 若仍有未做子项；已落地的子项可单独标完成，其余子项保持 parked/想法。  
5. **禁止**把「后期」当成「现在开做」；先查父树再补节点。  
6. 永远不做 → 子项 `archived`/`放弃` + 原因；以后要做 → **`parked` / 想法** + 完整延期卡。  
7. **防双盲**：延期卡 + 父/当前冲刺的 `suggestedNextStep` 必须让人扫一眼就知道——现在做什么、什么不做、什么以后做、做完接哪条。收工回复也要复述这几句；禁止「记过但双方都想不起来下一步」。  
8. **插队搁置**：被新需求挤下去的原计划，按 `star-pm-write-release`「插队 · 归队」写入停车场/下一步队列；插队项做完必须接回，不得静默失踪。

## 延期卡模板（每个子项必填，同批同规格）

```text
【是什么】一句话范围 + 边界（含/不含）
【为什么本期不做】裁切原因（周期/依赖/风险/用户原话）
【前期已落地】依赖哪些已完成切片（ID 更好）
【后期怎么做】入口、数据、规则、UI、验收（可扫）
【不做混淆项】容易跟本条搞混、但不在范围内的东西
【触发重开】什么信号才从停车场捞出来开做
【同批兄弟】列出同一次裁切的其他子项 ID/标题（证明没漏、没偏科）
```

`suggestedNextStep`：写成「停车场：…；重开条件：…」，不要写成当前冲刺任务。

## 造命 · Buff 整套同批子项（示例，平等）

父：`idea-40cde74d` / 需求 epic「造命·流年Buff整套（后期）」  
同批提出（方案 3 /「先 2 后期整套」）：下列子项落盘时同等对待。

| 子项 | 含义摘要 | 状态约定 |
|------|----------|----------|
| 子·大运+流年十神入词条 | 八字大运/流年十神进限时词条并弱改有效分 | 已完成切片亦可记为子·完成 |
| 子·流月Buff | 限时词条按月；八字流月十神为主；非时间梯 UI | 后期 parked |
| 子·多词条冲突细则 | 同轴过叠封顶/衰减/叙事优先级 | 后期 parked |
| 子·天气×行动叙事打通 | 八字=天气、紫微=行动；分区文案与乘子叙事 | 随 A 落地则子·完成，缺块则 parked |

流月细则（与上表同级，不是「唯一主角」）：`buildLuckCycles.liuyue`；`lane:'bazi' kind:'流月'`；月份切换；乘子弱于流年十神；夹紧 0.5～1.8。

## 落盘步骤

1. 定稿/收工用表格列出本期 **做 / 不做**（不做列写全，勿漏项）。  
2. 若无父包：建父 Idea + 父需求（`epic`）。  
3. **对不做列每一项**（含已决定先做的切片）：挂父下建子 Idea + 子需求，**逐条填满延期卡**；同批共用同一 `priority` 档（除非用户当场改档）。  
4. 父 `suggestedNextStep` 写「见子·甲/乙/丙」，不要只点名其中一个。  
5. 可选：`add_decision` 记裁切。  
6. 用户说「单独任务」但语境是确认后期 → 先查父树；补齐**同批全部子节点**，勿只补被点名的那一条。

## 反例 → 正例

| 反例 | 正例 |
|------|------|
| 同批四条只给「流月」写长卡，冲突细则一笔带过 | 四条子节点各一张完整延期卡 |
| 「后期补流月」另开顶层任务开干 | 挂 Buff 整套父下，与兄弟子项并列 |
| 整套标 done，子项没做完 | 已做子项标完成；未做子项仍想法/parked |
| 只把用户刚提到的那条升 P、其余降级 | 同批同 P；用户要改档时整批说明 |
