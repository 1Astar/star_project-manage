# Writing Plans（Star 覆盖版）

**覆盖** Codex `writing-plans` 在 Star 工作区的默认落点。

## 硬规则

1. **不要**写 `docs/superpowers/plans/YYYY-MM-DD-*.md`（除非用户明确要 plan 文件）。
2. 把任务拆解写进 **Star PM**：
   - ChangeSession：`expected` / `pendingItems` / `doneItems`
   - Idea / 需求：摘要、下一步、`module`
   - 必要时 `add_decision` / `add_evolution`
3. 拆任务仍可按「小步、可验、可勾」——只是载体是 PM，不是 markdown plan。
4. 对齐后按 `star-pm-write-release` 开做与收工。
