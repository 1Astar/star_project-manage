# 咨询风 PPT（科技蓝 + 纸感）

与 `doc-delivery-formats`、`version-management` 联用。  
**杂志风 / 横向网页 PPT / 多页 SVG** → 用 `guizang-ppt-skill` 或 `ppt-master`，不要用本 skill。

## 视觉方向

- **气质**：科技蓝咨询风 — 专业、可信、留白充足、信息层级清晰
- **纸感**：浅暖底或微纹理感背景（非纯白刺眼）；卡片轻阴影或细边框
- **主色**：深蓝系（与 Word 商务版对齐，如 **#1F3864 / #365F91 / #8FAADC**）
- **强调**：关键数字大号 + 高对比；风险/警示少量红色 **#C00000**
- **禁止**：荧光色、超过 3 种主色色相、每页塞满字、装饰抢内容

## 字体

- 中文：微软雅黑 / 思源黑体类无衬线
- 英数：Arial / Helvetica 或 Times 类（与 Word 交付一致时优先 Times）
- 标题加粗；正文不小于 18pt 投影 equivalent

## 页面类型（按需组合）

| 类型 | 用途 |
|------|------|
| 封面 | 项目名 + 副标题 + 日期/版本 |
| 章节幕封 | 单个大章号 + 短句 |
| 观点页 | 一句结论 + 3 条支撑 |
| 数据大字报 | 1–3 个核心数字 + 简短释义 |
| 对比表 | 竞品/方案矩阵，表头深蓝底白字 |
| 时间线/流程 | 横向步骤，≤5 步 |
| 结尾 | 下一步 / 风险 / Q&A |

## 叙事结构（商业调研典型）

1. 背景与问题  
2. 方法与范围  
3. 核心发现（数据页）  
4. 机会 / 风险窗口  
5. 建议与路线图  
6. 附录（可选，放详细表）

## 输出形式

按用户要求选择：

- **`.pptx`**：Office 可编辑（python-pptx / 模板填充 / 导出链）  
- **单文件 HTML PPT**：适合分享预览（可配合 guizang 技术栈，但视觉仍走本 skill 的咨询蓝规范）

生成后验证：投影可读、对比度足够、动画克制（默认无花哨转场）。

## 与 Word 一致

同一项目若既有 Word 又有 PPT：配色、术语、版本号、核心数字**必须一致**；先定 Word 或 PPT 主稿再派生另一格式。
